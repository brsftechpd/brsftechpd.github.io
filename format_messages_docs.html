Инструкции

Обзор инструмента

Инструмент «Формирование текста для Telegram» позволяет быстро создавать стандартизированные сообщения с данными заявок для отправки в рабочие чаты.

1

Назначение

Инструмент генерирует готовые текстовые блоки на основе введённых данных (номер заявки, UUID, дата) для трёх категорий:

  • Аутентификация — сообщение о статусе процесса аутентификации.
  • МСО — различные сообщения об ошибках или статусах обработки в МСО (process, docValidTo, middleName, ФЛ из ЕСФЛ, birthCountryId, firstNameLat, birthPlace).
  • Телеметрия — сообщение об отсутствии данных в навигаторе.

Важно: Все сгенерированные сообщения автоматически копируются в буфер обмена и сохраняются в историю для повторного использования.

2

Базовый сценарий

1. Заполните поля «Номер заявки», «UUID» (23 цифры) и выберите дату.

2. Выберите нужную категорию и нажмите соответствующую кнопку (например, «Аутентификация», «Process»).

3. Сообщение появится в поле результата и автоматически скопируется в буфер обмена.

4. При необходимости скопируйте сообщение вручную кнопкой «Копировать» или используйте историю для повторной отправки.

Ввод данных

Поля для заполнения и особенности их поведения.

1

Поле «Номер заявки»

Предназначено для ввода номера заявки (произвольный набор цифр). Принимает только цифры, нецифровые символы игнорируются. Поле обязательно для генерации любого сообщения.

2

Поле «UUID»

Ожидает 23 цифры (идентификатор пользователя). Ввод ограничен 23 символами, все нецифровые знаки автоматически удаляются. Если вставить из буфера обмена строку длиннее 23 цифр, она будет обрезана.

3

Поле «Дата»

Стандартное поле выбора даты. При загрузке страницы автоматически устанавливается сегодняшняя дата. Используется в сообщениях, требующих указания даты (например, «Аутентификация в статусе process: ДД.ММ.ГГГГ»).

4

«Умная» вставка из буфера обмена

Если фокус не находится в полях ввода, при нажатии Ctrl+V скрипт анализирует содержимое буфера обмена: числовые данные длиной ≤ 23 символа вставляются в поле UUID, более длинные — в поле «Номер заявки». Это ускоряет заполнение при копировании данных из других систем.

Важно: Вставка сработает, только если в буфере обмена есть хотя бы одна цифра. Иначе появится предупреждение.

Валидация: Если какое-либо поле не заполнено или заполнено некорректно, при нажатии на кнопку генерации появится уведомление об ошибке, а некорректные поля подсветятся красной рамкой.

Генерация сообщений

Описание всех кнопок и шаблонов генерируемых сообщений.

1

Группа «Аутентификация»

Кнопка «Аутентификация» формирует сообщение:

Номер заявки: {номер}
UUID: {uuid}
Аутентификация в статусе process: {дата}
2

Группа «МСО»

Содержит семь кнопок для различных ситуаций обработки в МСО:

  • Process — «МСО в статусе process: {дата}»
  • docValidTo — «МСО в статусе failedStop: Дата окончания действия документа находится в прошлом или формат переданных данных неверен.»
  • middleName — «МСО в статусе failedStop: Отчество содержит недопустимые символы.»
  • ФЛ из ЕСФЛ — «МСО в статусе failedStop: Произошла непредвиденная ошибка при отождествлении ФЛ в ЕСФЛ.»
  • birthCountryId — «МСО в статусе failedStop: В заявлении отсутствует информация о стране рождения.»
  • firstNameLat — «МСО в статусе failedStop: Имя содержит недопустимые символы.»
  • birthPlace — «МСО в статусе failedStop: Место рождения содержит недопустимые символы.»

Все сообщения начинаются с «Номер заявки: ...» и «UUID: ...», что делает их универсальными для рабочего чата.

Группа «Телеметрия»

Кнопка «Нет телеметрии» генерирует сообщение:

UUID: {uuid}

История и копирование

Работа с историей сообщений и сохранение результатов.

1

Отображение результата

Сгенерированное сообщение сразу появляется в блоке «Сформированное сообщение» под полями ввода. Рядом находится кнопка «Копировать» — она дублирует автоматическое копирование. Если сообщение ещё не было сгенерировано, при нажатии на кнопку появится предупреждение.

Пример блока результата:
Номер заявки: 12345
UUID: 12345678901234567890123
Аутентификация в статусе process: 11.05.2026
2

Панель истории

Справа от основного блока (или под ним на мобильных устройствах) расположена история последних 20 сгенерированных сообщений. Каждая запись кликабельна — при нажатии она подставляется в поле результата. При наведении появляются кнопки:

  • — использовать сообщение (аналог клика)
  • — удалить запись из истории

Кнопка «Очистить историю» полностью удаляет все записи (с подтверждением). История автоматически сохраняется в localStorage браузера, поэтому доступна даже после перезагрузки страницы. Дубликаты сообщений не сохраняются — новое вхождение перемещается в начало списка.

Используйте историю, чтобы быстро повторять часто отправляемые типовые сообщения без повторного ввода данных.

3

Уведомления

В правом верхнем углу экрана появляются временные уведомления (зелёные — успех, красные — ошибка). Они сообщают о статусе копирования, ошибках валидации или других действиях. Уведомления исчезают автоматически через 3 секунды.

Советы по использованию

Рекомендации для эффективной работы с инструментом.

1

Горячие клавиши

  • Ctrl+V (когда поля ввода не в фокусе) — «умная» вставка числовых данных из буфера обмена в нужное поле.
2

Эффективная работа

  • Если нужно быстро сообщить о нескольких ошибках по одной заявке, после первой генерации просто нажимайте другие кнопки — поля остаются заполненными.
  • Для однотипных заявок с разными UUID используйте вставку из буфера обмена, чтобы переключаться между ними.
  • Дата всегда подставляется сегодняшняя; если требуется указать другую дату, измените её вручную перед генерацией.
  • Историю можно использовать как «избранное» для часто используемых шаблонов — просто не очищайте её.

Важно: Для корректной работы инструмента необходим доступ к буферу обмена. При использовании в защищённых средах (например, HTTP-страницы) функция копирования может быть ограничена — используйте HTTPS.
