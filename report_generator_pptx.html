Инструкция по использованию:

1. Загрузите файл PPTX с метками (ДАТА, А.ПОКАЗАТЕЛЬ, У.ПРОЦЕНТ, Б.ПОКАЗАТЕЛЬ, И.ЧИСЛО и т.д.)

2. Введите все данные в форму (можно вводить дробные числа, например: 2 021,2 или 0,001)

3. Нажмите "Обновить данные в PPTX" для обработки файла

4. Скачайте обновленный файл презентации

Важно: В отчете прирост (все поля *.ЧИСЛО) будет отображаться со знаком "+", если значение больше 0.
