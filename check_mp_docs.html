Инструкции

Обзор инструмента

Мониторинг МП — это панель быстрого доступа к аналитическим запросам OpenSearch для контроля работы сервисов мобильного приложения.

1

Назначение

Инструмент предоставляет структурированный доступ к преднастроенным поисковым запросам OpenSearch, сгруппированным по функциональным категориям:

  • Регистрация, авторизация, капча
  • Профиль, идентификация, постановка на учет
  • Геолокация, телефон, пуш-уведомления
  • Документы, FAQ, мигрант-сервис

Важно: Все ссылки ведут в изолированную среду OpenSearch и открываются в новых вкладках.

2

Базовый сценарий

1. Выберите нужную категорию в боковой панели

2. Найдите интересующий сервис

3. Нажмите «Проверить работу» для просмотра логов или «Найти ошибки» для отфильтрованных ошибок

4. При необходимости скопируйте прямую ссылку кнопкой

Категории и сервисы

Все сервисы сгруппированы по бизнес-логике мобильного приложения.

1

Навигация по категориям

В левой боковой панели расположен список категорий с иконками. Просто кликните по нужной категории, чтобы увидеть входящие в неё сервисы.

2

Доступные категории

  • Регистрация — проверка регистрации по паспорту и КИГ, запросы в ММЦ
  • Авторизация — вход в приложение, сервисы auth и ММЦ адаптер
  • Капча — генерация и проверка капчи
  • Профиль — получение данных профиля
  • Идентификация и Аутентификация — фото, биометрия, ECHD
  • Постановка на учет — адрес проживания, миграционный учёт
  • Установка места сна и отдыха — изменение адреса, геокодер
  • Передача геолокации — отправка координат
  • Подтверждение номера телефона — SMS-верификация
  • Пуш-уведомления — push-сервисы
  • Документы — загрузка и проверка документов
  • FAQ — справочные материалы
  • Мигрант сервис — авторизация мигрантов, токены

Проверка работы сервисов

Быстрый переход к логам для оценки текущего состояния сервиса.

1

Кнопка «Проверить работу»

Для каждого сервиса в карточке есть кнопка «Проверить работу». Она открывает OpenSearch с преднастроенным фильтром по выбранному сервису, показывая все логи за последние 6 часов.

2

Интерпретация результатов

После перехода в OpenSearch вы увидите таблицу логов. Обратите внимание на столбцы:

  • message — текстовое сообщение лога
  • level — уровень (info, error, fatal)
  • app — название сервиса
  • properties.UserId — UUID пользователя (если есть)

При отсутствии явных проблем количество ошибок будет минимальным.

Поиск ошибок

Отфильтрованные запросы, показывающие только проблемные логи.

1

Кнопка «Найти ошибки»

Кнопка «Найти ошибки» аналогична «Проверить работу», но добавляет фильтр по уровням error и fatal. Это позволяет быстро выявить сбои без просмотра информационных сообщений.

Обратите внимание: Некоторые сервисы могут иметь специфические исключения для фильтрации (например, исключение ошибок обновления приложения).

2

Дополнительные фильтры

Для ряда сервисов в запросах уже применены дополнительные условия, чтобы отсечь нерелевантные ошибки (например, исключение ответов с кодами 200, 204 или специфических сообщений). Это делает анализ более точным.

Копирование ссылок

Прямые ссылки на аналитику для обмена с коллегами или сохранения.

1

Кнопки копирования

Рядом с каждой кнопкой действия находится иконка . Нажатие на неё копирует соответствующую OpenSearch-ссылку в буфер обмена. После успешного копирования иконка временно меняется на галочку.

Использование скопированных ссылок

Скопированную ссылку можно отправить коллеге, вставить в задачу или сохранить в закладки. Она откроет ту же самую страницу OpenSearch с уже настроенными фильтрами.

Ссылки содержат временной диапазон «последние 6 часов», поэтому при повторном открытии они всегда показывают актуальные данные.

Советы по использованию

Рекомендации для эффективного мониторинга.

1

Эффективная работа

  • Используйте фильтр ошибок для быстрого обнаружения инцидентов
  • Копируйте прямые ссылки для документирования проблем
  • Периодически проверяйте все категории, чтобы иметь полную картину состояния системы
  • При анализе ошибок обращайте внимание на properties.UserId — это поможет воспроизвести проблему у конкретного пользователя

Важно: Все ссылки ведут во внутреннюю сеть. Для доступа требуется авторизация в OpenSearch.
