Инструкции

Обзор инструмента

UUID Tools — это веб-инструмент для выполнения типовых операций с идентификаторами пользователей (UUID) и связанными данными.

1

Основные функции

Инструмент предоставляет быстрый доступ к следующим функциям:

  • Форматирование UUID для S3-путей
  • Аналитические запросы в OpenSearch
  • Поиск профилей по паспорту и КИГ
  • Генератор МСО запроса — конструктор адреса для Многофункционального Сервисного Офиса

Обязательно: Для всех операций с UUID требуется 23-значный числовой идентификатор.

2

Базовый сценарий работы

1. Введите UUID в основное поле

2. Используйте одну из кнопок для нужного действия

3. Если действие было "форматировать", то результат автоматически копируется в буфер обмена. В остальных случаях открывается новая вкладка с логами OpenSearch

Поиск по КИГ

Поиск профилей по номеру Карты Иностранного Гражданина.

1

Ввод номера КИГ

Обязательно: 9 символов в формате AA1234567 или AB1234567

Поле автоматически конвертирует русские буквы в латинские и принимает только допустимые символы.

Поле ввода КИГ:

Формат: Допустимы только префиксы AA или AB, затем 7 цифр.

2

Поиск

Нажмите кнопку поиска или клавишу Enter. Откроется новая вкладка с результатами в OpenSearch.

Генератор МСО запроса

Конструктор для формирования JSON-запроса МСО.

1

Заполнение полей

Введите данные в соответствующие поля:

  • timestamp — дата и время
  • changeDate — дата изменения
  • addressName — название адреса
  • street — улица
  • house — номер дома
  • flat — номер квартиры
  • latlon — координаты в формате широта, долгота
  • province — регион/область
  • city — город
2

Генерация и копирование результата

Нажмите кнопку «Сгенерировать JSON». Сформированный JSON-объект появится в поле вывода и автоматически скопируется в буфер обмена.

Вы также можете скопировать результат вручную, кликнув по кнопке копирования.

Пример результата:
{ "locality": null, "vegetation": null, "addressName": "Москва, улица Ленина, дом 22, квартира 33", "flat": "33", "street": "Ленина", "house": "22", "province": "Центральный федеральный округ", "city": "Москва", "point": { "lat": 55.947878, "lon": 37.932549 }, "timestamp": "2026-07-15T06:52:51.653000Z", "district": null, "changeDate": "2026-07-15T06:52:51Z", "savedToDbTimestamp": null, "isOtherSpace": null, "uuid": "01234567890123456789012" }

Важно: Убедитесь, что все обязательные поля заполнены корректно, иначе генерация будет заблокирована (поля с ошибками подсветятся красным).

После генерации JSON автоматически копируется — вы можете сразу вставить его в нужное место (например, в тело запроса).

Советы по использованию

Полезные рекомендации для эффективной работы.

1

Быстрая вставка

Вставьте текст с UUID в любое место страницы — инструмент автоматически распознает 23-значный номер.

2

Горячие клавиши

  • Enter в поле UUID — форматирование
  • Enter в поле паспорта — проверка регистрации
  • Enter в поле КИГ — поиск
  • Enter в любом поле генератора МСО — генерация JSON
3

Эффективная работа

  • Используйте переключатель профиль/фото для правильного префикса
  • Аналитические запросы открываются в новых вкладках — можно работать параллельно
  • Результаты автоматически копируются в буфер обмена
  • Очищайте статистику в конце рабочего дня

Важно: Всегда проверяйте, что UUID содержит ровно 23 цифры перед выполнением операций.
