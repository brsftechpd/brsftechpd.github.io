Инструкции

Обзор инструмента

База знаний — это структурированное хранилище шаблонов ответов, рекомендаций и проверок для поддержки пользователей.

1

Назначение

Инструмент предоставляет быстрый доступ к готовым ответам и инструкциям, разделённым по категориям. Каждый шаблон содержит текстовое содержимое и метаданные:

  • Тип шаблона: рекомендация, информация, проверка
  • Теги для быстрого поиска
  • Индикатор соответствия базе знаний (полное, частичное, отсутствует)
  • Даты создания и обновления

Важно: Все шаблоны загружаются из централизованного источника и периодически обновляются.

2

Базовый сценарий

1. Выберите нужную категорию в боковой панели или воспользуйтесь поиском

2. Найдите подходящий шаблон по названию или тегам

3. Нажмите на шаблон, чтобы увидеть полное содержимое

4. Скопируйте готовый ответ кнопкой «Копировать для ответа» или поделитесь ссылкой

Категории и шаблоны

Организация знаний по тематическим группам.

1

Навигация по категориям

В левой боковой панели расположен список категорий с иконками и количеством шаблонов. Кликните по категории, чтобы отфильтровать список шаблонов. Категория «Все шаблоны» показывает полный перечень.

2

Избранные категории

Любую категорию можно добавить в избранное, нажав на звёздочку рядом с названием. Избранные категории отображаются вверху списка и позволяют быстрее находить нужные разделы.

3

Шаблоны и их типы

В центральной колонке отображаются шаблоны выбранной категории. Они сгруппированы по типу:

  • Рекомендации — готовые тексты для ответа пользователям
  • Информация — справочные материалы
  • Проверки — алгоритмы диагностики проблем

Каждый шаблон имеет цветной индикатор соответствия базе знаний (зелёный — полное, оранжевый — частичное, красный — не соответствует).

Поиск и фильтрация

Быстрый поиск по содержимому шаблонов.

1

Поиск по ключевым словам

В верхней части центральной колонки находится поле поиска. Введите запрос — фильтр применяется мгновенно. Поиск ищет совпадения в названии, описании, тегах и тексте шаблона.

Пример поиска:
восстановление пароля
2

Фильтрация по тегам

При просмотре шаблона в правой части отображаются теги. Нажатие на тег копирует его в буфер обмена, и вы можете вставить его в поисковую строку для быстрого фильтра.

Копирование и шаринг

Быстрое получение готового ответа и обмен ссылками.

1

Копирование для ответа

Кнопка «Копировать для ответа» копирует содержимое выбранного шаблона в буфер обмена в формате HTML и обычного текста. Кнопка временно меняет цвет и текст, подтверждая действие.

2

Режим «Копировать при клике»

В нижней части центральной колонки есть переключатель «Копировать при клике». Если он активирован, то при выборе шаблона его содержимое автоматически копируется в буфер обмена. Это ускоряет работу с часто используемыми ответами.

Используйте этот режим, если вам нужно быстро отвечать на типовые запросы без лишних кликов.

3

Поделиться ссылкой на ответ

Кнопка «Поделиться ссылкой на ответ» копирует в буфер обмена прямую ссылку на текущий шаблон. Отправив эту ссылку коллеге, он сразу откроет нужный шаблон в своей Базе знаний.

Настройки и внешний вид

Персонализация интерфейса под ваши предпочтения.

1

Переключение темы

В левом нижнем углу находится кнопка переключения темы. Доступны три режима:

  • Тёмная тема (по умолчанию)
  • Светлая тема
  • Авто — тема следует системным настройкам

2

Сворачивание боковой панели

Кнопка со стрелкой в заголовке «Категории» сворачивает левую панель, оставляя только иконки категорий. Повторное нажатие разворачивает панель обратно. Состояние сохраняется между сессиями.

3

Обновление данных

Данные автоматически проверяются на обновления каждые 10 минут. При обнаружении изменений внизу левой панели появляется кнопка «Обновить данные». Нажмите её, чтобы загрузить актуальную версию шаблонов.

Советы по использованию

Рекомендации для эффективной работы с Базой знаний.

1

Эффективная работа

  • Добавьте часто используемые категории в избранное для мгновенного доступа
  • Используйте поиск по тегам, копируя их кликом в детальном виде
  • Включите режим «Копировать при клике» для ускорения ответов на типовые запросы
  • Делитесь прямыми ссылками на шаблоны с коллегами — это экономит время на поиск
  • Следите за индикатором соответствия БЗ: зелёный — проверенный ответ, красный — требует уточнения

Важно: Содержимое шаблонов обновляется централизованно. Если вы заметили устаревшую информацию, сообщите администратору.
