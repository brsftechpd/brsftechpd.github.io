Обзор инструмента

QR-сканер — это простой и быстрый способ распознавания UUID из QR-кодов с возможностью копирования как чистого значения, так и с добавлением стандартизированных комментариев.

1

Назначение

Инструмент предназначен для:

  • Мгновенного считывания QR-кодов, содержащих UUID (например, идентификаторы пользователей, устройств).
  • Копирования полученного UUID в буфер обмена одним нажатием.
  • Автоматического добавления пояснительных суффиксов к UUID для удобства документирования ошибок и обращений.

Важно: Для работы сканера необходим доступ к камере. Страница должна быть открыта по HTTPS или localhost.

2

Базовый сценарий

1. Нажмите кнопку «Включить камеру» и разрешите доступ к камере в браузере.

2. Наведите камеру на QR-код так, чтобы он попал в область сканирования.

3. После успешного распознавания UUID появится в поле результата.

4. Кликните по полю с UUID, чтобы скопировать его, или воспользуйтесь одной из кнопок с комментариями (например, «Нет учета в МВД»).

Использование сканера

Подробное описание процесса сканирования и элементов интерфейса.

1

Запуск и остановка камеры

Управление камерой осуществляется единственной кнопкой в верхней части карточки инструмента. Она меняет свой вид в зависимости от состояния:

  • Включить камеру () — запускает видеопоток с камеры и начинает поиск QR-кодов.
  • Выключить камеру () — останавливает сканирование и освобождает камеру.

2

Область сканирования

Видеопоток с камеры отображается в прямоугольной области под кнопкой управления. При наведении на QR-код происходит его автоматическое распознавание. Никаких дополнительных действий не требуется.

По умолчанию выбирается задняя камера устройства (если доступна), чтобы облегчить наведение.

Для наилучшего результата держите QR-код ровно, избегайте бликов и обеспечивайте хорошее освещение.

3

Поле результата

Сразу под видео расположено поле, в котором отображается распознанный UUID. Пока код не считан, в поле выводится подсказка «Отсканируйте QR‑код». После распознавания текст становится кликабельным — один клик копирует чистый UUID.

Копирование результатов

Все способы извлечения и дополнения распознанного UUID.

1

Прямое копирование UUID

Кликните по полю с распознанным UUID — значение будет скопировано в буфер обмена без каких-либо изменений. Появится уведомление об успешном копировании.

Поле результата (кликабельное):
12345678901234567890123
2

Копирование с комментариями

Под полем результата расположены дополнительные кнопки. Каждая кнопка копирует UUID, добавляя к нему пояснительный текст (суффикс) с новой строки. Это удобно для документирования типовых проблем.

Доступные кнопки и их суффиксы:

  • Нет учета в МВД — добавляет «\nНет учета в базе данных МВД.»
  • Слетает МСО — добавляет «\nПри попытке указать адрес, отображается старый адрес или кнопка повторить.»
  • Нет блока МСО — добавляет «\nВ интерфейсе отсутствует блок Места сна и отдыха»
  • Не передается ГЕО — добавляет «\nНеобходимо проверить передачу геолокации.»

После нажатия любой из этих кнопок результирующий текст (UUID + комментарий) попадает в буфер обмена.

Советы по использованию

Рекомендации для эффективной работы со сканером.

1

Эффективная работа

  • Используйте заднюю камеру — она автоматически выбирается при запуске, если доступна.
  • При плохом освещении включите фонарик на устройстве или поднесите код ближе к источнику света.
  • Если сканирование не происходит, попробуйте слегка изменить расстояние или угол наклона.
  • Кнопки с комментариями экономят время при оформлении обращений — не нужно каждый раз вручную дописывать пояснения.
  • Для повторного сканирования не обязательно выключать камеру — просто поднесите следующий QR-код.

Внимание: Доступ к камере может быть запрещён на уровне браузера или операционной системы. Убедитесь, что для сайта разрешён доступ к камере. Работа гарантируется только при использовании HTTPS или localhost.

Важно: Сканер предназначен для распознавания QR-кодов, содержащих UUID. Коды с другими данными также будут прочитаны, но могут быть менее полезны в вашем контексте.
