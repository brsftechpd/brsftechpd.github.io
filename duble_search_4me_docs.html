Инструкции

Обзор инструмента

Ticket check 4me — это инструмент для анализа выгрузки заявок из системы 4me, который помогает быстро находить дублирующиеся, нестандартные и уникальные записи по инициатору запроса.

1

Назначение

Инструмент обрабатывает Excel-файл, выгруженный из 4me, и выполняет:

  • Нормализацию инициатора запроса (очистка от лишнего текста, приведение к стандартному формату).
  • Группировку записей по нормализованному инициатору.
  • Классификацию на дублирующиеся (повторяющиеся инициаторы), несоответствующие формату и уникальные верные.

Важно: Файл должен быть оригинальной выгрузкой из 4me в формате .xlsx или .xls. Обработка происходит полностью в браузере, данные не передаются на сервер.

2

Базовый сценарий

1. Загрузите Excel-файл с помощью кнопки или перетаскивания.

2. Переключайтесь между вкладками «Все», «Дублирующиеся», «Несоответствующие», «Уникальные» для просмотра разных групп записей.

3. Нажимайте на ID заявки, чтобы открыть её в 4me.

4. Копируйте инициатора запроса кликом по нему.

5. При необходимости удаляйте лишние записи или экспортируйте результат в Excel.

Загрузка файла

Поддерживаемые форматы и способы загрузки данных.

1

Выбор файла

Нажмите кнопку «Выбрать файл Excel» или перетащите файл прямо в область загрузки. Поддерживаются файлы с расширениями .xlsx и .xls.

Пример интерфейса загрузки:

Загрузите файл Excel

Перетащите файл сюда или нажмите для выбора

2

Устранение проблем с защищённым просмотром

Если после загрузки файла появляется сообщение об ошибке, вероятная причина — файл находится в режиме «Защищённый просмотр».

Чтобы это исправить:

  • Откройте файл в Microsoft Excel.
  • Если появится предупреждение, нажмите кнопку «Разрешить редактирование».
  • Сохраните файл (Файл → Сохранить как) и загрузите его заново.

Внимание: Инструмент не работает с файлами, защищёнными паролем или содержащими макросы.

Категории записей

Все заявки автоматически распределяются по четырём группам.

1

Навигация по категориям

В левой боковой панели расположены вкладки с количеством записей в каждой категории. Нажмите на нужную, чтобы увидеть соответствующие записи.

Пример боковой панели:
2

Описание категорий

  • Все — полный список заявок из файла.
  • Дублирующиеся — записи, у которых нормализованный инициатор повторяется (два и более раза).
  • Несоответствующие — инициатор запроса не соответствует стандартному формату (например, отсутствует шаблон «A B 1234567»).
  • Уникальные верные — записи с корректным форматом инициатора, которые встречаются в файле только один раз.

Работа с таблицей

Основные действия с данными после загрузки.

1

Интерактивные элементы строки

Каждая строка таблицы содержит:

  • ID — кнопка, при нажатии открывает заявку в 4me.
  • Инициатор запроса — кнопка, при нажатии копирует нормализованный инициатор в буфер обмена.
  • Тема — краткое описание заявки.
  • Действия — кнопка «Удалить», удаляющая запись из текущей сессии.
Пример строки таблицы:
IDИнициатор запросаТемаДействия
Проблема с регистрацией
2

Поиск и фильтрация

Над таблицей находится поле поиска. Введите любой текст — отфильтруются строки, содержащие его в любом столбце. При поиске в категории «Дублирующиеся» скрываются целые группы, если ни одна запись в группе не соответствует запросу.

3

Удаление записей

Кнопка «Удалить» убирает запись только из текущего просмотра. Это полезно, если вы хотите временно скрыть обработанные позиции. После перезагрузки файла все записи восстанавливаются.

Если нужно зафиксировать изменения, сначала экспортируйте таблицу в Excel, а затем используйте полученный файл.

Копирование и экспорт

Способы извлечения данных для дальнейшей работы.

1

Копирование инициатора

Нажмите на кнопку с инициатором запроса (например, AB1234567). Текст будет скопирован в буфер обмена, а кнопка на мгновение изменится на «Скопировано».

Экспорт в Excel

Кнопка «Экспорт в Excel» сохраняет текущую таблицу (без столбца «Действия») в файл формата .xlsx. Имя файла соответствует названию категории, например «Дублирующиеся_записи.xlsx».

Советы по использованию

Рекомендации для эффективной обработки заявок.

1

Эффективная работа

  • Начинайте анализ с вкладки «Дублирующиеся» — она сразу показывает потенциальные проблемы (один и тот же человек в нескольких заявках).
  • Используйте поиск, чтобы быстро найти конкретного инициатора или тему.
  • Удаляйте уже обработанные записи, чтобы не отвлекаться на них при повторном просмотре.
  • Если нужно передать результаты коллегам, экспортируйте нужную категорию в Excel.

Важно: Инструмент предназначен исключительно для работы с выгрузками из 4me. Использование файлов другой структуры может привести к некорректным результатам.
